# FE-03: Routing (react-router) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Thay routing tự chế (`window.location.pathname` + `useState` + `history.pushState` rải khắp `App.tsx`) bằng `react-router-dom`, với một bảng route tập trung, route guard theo `allowed_sections`, và gom luôn nhánh warranty đang xử lý thủ công ở `main.tsx`.

**Architecture:** Một `RootLayout` chứa Sidebar/topbar + `<Outlet/>`. Bảng route khai báo bằng `createBrowserRouter`. Mỗi page là một route con lazy-load (giữ nguyên `React.lazy`). Một `RequireAuth` + `RequireSection` guard bọc nhánh cần đăng nhập/quyền. Logic mapping pathname↔section/tab hiện có (`sectionFromPath`, `parseOrdersView`, `parseLandingTab`) được thay bằng `useParams`/`useSearchParams`. `App.tsx` co lại còn phần auth + layout state.

**Tech Stack:** react-router-dom v6 (data router API: `createBrowserRouter`, `RouterProvider`, `Outlet`, `useNavigate`, `useParams`, `useSearchParams`).

Giải quyết: P1 (routing tự chế bằng window.location).

**Phụ thuộc:** Nên làm sau FE-01. Có thể chạy song song FE-02.

- [ ] **Step 3: Viết `RequireAuth.tsx`**

```tsx
import { Navigate, useLocation } from "react-router-dom";
import type { ReactNode } from "react";

type AuthUser = { allowed_sections: string[] } | null;

export default function RequireAuth({
  user,
  section,
  children,
}: {
  user: AuthUser;
  section?: string;
  children: ReactNode;
}) {
  const location = useLocation();
  if (!user) {
    return <Navigate to="/login" replace state={{ from: location }} />;
  }
  if (section && !user.allowed_sections.includes(section)) {
    return <Navigate to="/" replace />;
  }
  return <>{children}</>;
}
```

- [ ] **Step 4: Chạy test → PASS**

Run: `cd frontend && npx vitest run src/app/__tests__/RequireAuth.test.tsx`
Expected: PASS.
